This project implements and evaluates various classification models on the German Credit Data with Risk dataset to predict credit risk. The models range from simple statistical techniques to advanced ensemble learning algorithms.

The dataset consists of demographic, financial, and credit history information for individuals in Germany applying for credit. The target variable is Risk, classified as either 'good' or 'bad'.
Models Implemented
Logistic Regression

K-Nearest Neighbors (KNN)

Naive Bayes

Decision Tree

Random Forest

Bagging

Boosting (e.g., AdaBoost, Gradient Boosting)

Voting Classifier

Support Vector Machine (SVM)
